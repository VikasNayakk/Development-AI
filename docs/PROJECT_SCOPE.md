# Project Scope

## Current milestone
Local AI model integration through Ollama.

## Included
- Chrome Manifest V3 extension chat.
- Local conversation storage.
- Node.js backend gateway.
- Ollama native chat API integration.
- Local model availability detection.
- Exact browser extension origin allowlist.
- Automated tests using a mock local Ollama server.

## Not included yet
- Ollama installation on the user's computer.
- Model download or live inference verification on the user's hardware.
- Browser page reading or automation.
- Desktop-wide control.
- Multi-user authentication or remote deployment.

The local runtime and model need to be installed on the target computer. Hardware requirements depend on the chosen model and quantization.
